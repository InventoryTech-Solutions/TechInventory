# TechInventory - Módulo Frontend

Este proyecto constituye la interfaz de usuario (UI) para el **Sistema de Gestión de Inventarios y Logística E-Commerce (TechInventory)** de E-Tech Logistics[cite: 2]. Fue desarrollado utilizando **Angular CLI** versión 21.2.13.

## 🚀 Servidor de Desarrollo

Para iniciar el servidor local de desarrollo, ejecuta:

```bash
ng serve

Una vez que el servidor esté en ejecución, abre tu navegador e ingresa a http://localhost:4200/. La aplicación se recargará automáticamente ante cualquier cambio en los archivos fuente.

🛠️ Generación de Código (Scaffolding)
Puedes utilizar la CLI de Angular para generar nuevos componentes, servicios, directivas y más:

# Generar un nuevo componente
ng generate component nombre-del-componente

# Ver la lista completa de esquemáticos disponibles
ng generate --help

📦 Compilación (Build)
Para compilar el proyecto y generar los artefactos de producción:

ng build
