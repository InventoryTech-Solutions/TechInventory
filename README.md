# 📦 TechInventory - Sistema de Gestión Eficiente de Inventarios & Logística E-Commerce

**E-Tech Logistics Chile S.A.**

Proyecto integral de gestión de inventario, sincronización en tiempo real y trazabilidad logística desarrollado en arquitectura modular.

---

## 🏗️ Estructura del Proyecto

Este repositorio está organizado como un monorepo modular conteniendo:

* **`/frontend-inventory`**: Aplicación Web desarrollada en **Angular** para la interfaz operativa y paneles de usuario.
* **`/backend-inventory`**: API RESTful desarrollada en **Java Spring Boot** para la lógica de inventarios y datos.

---

## ⚙️ Requisitos de Entorno

* **Node.js** v18+ & **Angular CLI** 21+
* **Java Development Kit (JDK)** 21+
* **PostgreSQL** 15+
